# Cambios aplicados a Embocadura Organizada

## Objetivo

Acortar la página y hacerla más directa, manteniendo el branding de Escuela de Flautistas, los mockups existentes y la fotografía de Valentina Galaz.

## Cambios principales

- Hero más directo con promesa clara: reorganizar la embocadura y transformar el sonido en 21 días.
- Oferta resumida desde el inicio:
  - 21 videos diarios.
  - Agenda imprimible.
  - Guía de indicaciones.
  - Bonus progresivos.
  - Set de partituras final.
  - Certificado de finalización.
  - Acceso por 1 año.
- Se redujo el texto largo y repetitivo.
- Se mantuvo una sección breve de dolor/problema.
- Se agregó una explicación simple de cómo funciona.
- Se incorporó la liberación progresiva de bonus:
  - Respiración.
  - Activación articular.
  - Liberación de tensiones.
  - Set de partituras al finalizar el día 21.
- Se agregó sección de cierre con certificado.
- Se actualizó la sección de precio para listar todo lo incluido.
- Se simplificó el FAQ con dudas reales:
  - Si el curso es en vivo.
  - Si hay que enviar videos.
  - Qué pasa si la persona se atrasa.
  - Cuándo se liberan los bonus.
  - Qué recibe al terminar.
  - Si necesita estudiar horas.
  - Cuándo recibe el acceso.

## Recursos visuales mantenidos

- Portada del desafío.
- Mockup principal.
- Mockup de materiales imprimibles.
- Mockup de plataforma.
- Foto de Valentina Galaz.
- Paleta roja, menta, beige, grafito.
- Tipografías Montserrat y Cormorant Garamond.
